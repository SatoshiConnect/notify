เชื่อมต่อระบบ

ส่ง HTTP request จากเซิร์ฟเวอร์ของคุณมายัง Notify

  1. สร้างบอตคัดลอก API key จากแท็บบอตและเก็บไว้เป็นความลับบนเซิร์ฟเวอร์ของระบบต้นทาง
  2. เลือกผู้รับสร้างกลุ่มผู้รับหนึ่งคนสำหรับแจ้งเตือนส่วนตัว หรือเลือกหลายคนเพื่อแจ้งเข้ากลุ่ม แล้วใช้ groupId ผู้รับต้องเป็นเพื่อนในแชทกับบัญชีเจ้าของบอต
  3. ส่งเหตุการณ์เรียก API พร้อมชื่อเรื่อง ข้อความ เวลา และรูป Data URL (ถ้ามี)
